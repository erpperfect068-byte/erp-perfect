# User Preferences and Behavioral Rules

## Critical Rule: Explain First Before Executing Edits or Pushes
- When the user asks a question, inquires about code logic, architecture, security, or "why/how" something works, **ALWAYS explain first**.
- **DO NOT** make automatic file edits, commits, or git pushes immediately upon a question.
- Present the explanation and options clearly, and wait for explicit user confirmation before executing any code modifications or git operations.
